1. MİNİMUM VE ÖNERİLEN SİSTEM GEREKSİNİMLERİ
--------------------------------------------------------------------------------
• İşletim Sistemi : Windows 10/11, Ubuntu 20.04+, macOS Sonoma+
• Node.js         : Node.js v18.17.0 veya daha yüksek (Önerilen: Node.js v20.x LTS)
• Paket Yöneticisi: npm v9.x+ (Node.js ile birlikte gelir) veya yarn / pnpm
• İşlemci (CPU)   : 2 Çekirdek 2.0 GHz ve üzeri (Önerilen: 4 Çekirdek 3.0 GHz)
• Bellek (RAM)    : Minimum 4 GB RAM (Önerilen: 8 GB+ RAM)
• Depolama        : 1 GB kullanılabilir disk alanı
• Veritabanı      : SQLite (Yerleşik - Dahili kurulum gerektirmez, Prisma ORM hazır)

3. ADIM ADIM KURULUM VE ÇALIŞTIRMA TALİMATLARI
--------------------------------------------------------------------------------

[Adım 1] Dosyaları Klasöre Çıkarma:
----------------------------------
ZIP dosyasını istediğiniz sunucu veya yerel çalışma dizinine çıkarın.

[Adım 2] Bağımlılıkları Yükleme (npm install):
----------------------------------------------
Komut satırını (Terminal / PowerShell) proje klasöründe açın ve çalıştırın:
> npm install

[Adım 3] Veritabanı Kurulumu (Prisma SQLite):
---------------------------------------------
Yerel veritabanı tablolarını ve şemasını oluşturmak için:
> npx prisma db push

Admin kullanıcısını veritabanına eklemek / güncellemek için:
> node create_admin_user.js

[Adım 4] Geliştirici Modunda Çalıştırma (Dev Mode - Port 3005):
--------------------------------------------------------------
> npx next dev -p 3005
Veya pakette tanımlı varsayılan port ile:
> npm run dev

Uygulamaya erişim: http://localhost:3005

[Adım 5] Canlı Canlı Üretim Derlemesi Almak (Production Build):
----------------------------------------------------------------
> npm run build
> npm run start
